Todo lo que tenés para leer o mirar.
Y dónde quedaste.

Una biblioteca, lector y reproductor auto-alojado para el manga, los cómics, las películas, las series y el anime de tu propio disco. Un solo lugar para seguir, la página y el minuto guardados, y una API para tus herramientas.

Instalar El código en GitHub

La biblioteca: primero lo que dejaste por la mitad, después todo, leído o visto.

Qué hace

Un lector

CBZ, ZIP, PDF o carpetas de imágenes. De derecha a izquierda para manga, de izquierda a derecha para cómics, vertical para webtoons, de a dos páginas. Teclado, toques y gestos.

Un reproductor

Lo que el navegador reproduce sale directo, y se puede adelantar. Lo demás se convierte una sola vez con ffmpeg (con la GPU si hay). Subtítulos y el episodio siguiente.

Recuerda

El tomo y la página, el episodio y el minuto. Un estante de «seguir» para todo, y un registro de lo que terminaste.

En el celular

Un catálogo OPDS para Panels, Chunky, KOReader o Mihon. Las páginas llegan de a una, y lo que leés ahí mueve el mismo «seguir».

Una API

Obras, unidades, páginas, fotogramas sueltos, progreso y eventos, con token. Tu red de casa y Tailscale pueden entrar sin él.

Lo que nunca va a hacer

  • Traer las obras. Ni descargas, ni scraping, ni listas de fuentes. Lee los archivos que ya tenés.
  • Llamar a casa. Sin cuenta, sin nube, sin telemetría. Solo consultas de metadatos, si las activás.
  • Adueñarse de tus archivos. Las carpetas mandan: se copian con rsync y se respaldan sin que archivist corra. La base solo guarda dónde quedaste.
  • Cortar clips para nadie. Las herramientas reciben páginas y fotogramas sueltos. La reproducción es para tu pantalla.

Instalar

Docker

docker build -t archivist https://github.com/legiosai/archivist.git
docker run -d --name archivist -p 8780:8780 \
  -v /ruta/a/la/biblioteca:/library -v archivist-data:/data \
  -e ARCHIVIST_TOKEN="$(openssl rand -hex 24)" \
  -e ARCHIVIST_TRUSTED=lan,tailscale archivist

Desde el código

git clone https://github.com/legiosai/archivist
cd archivist && npm ci && npm run build
ARCHIVIST_LIBRARY=/ruta/a/la/biblioteca \
ARCHIVIST_TOKEN=… npm start

Node 22 o más nuevo, ffmpeg y poppler. En deploy/ hay una unidad de systemd.

La biblioteca en disco

library/
  video/<obra>.mp4 + <obra>.yaml           una película
  video/<obra>/S01E01.mkv … + work.yaml     una serie o un anime
  pages/<obra>/tomo-01.cbz … + work.yaml    un manga o un cómic
